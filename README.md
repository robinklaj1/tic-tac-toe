# Tic Tac Toe

A simple tic-tac-toe game you can play in the browser.

## Play

Open the live game: **https://robinklaj1.github.io/tic-tac-toe/**

## Features

- 2-player local mode
- vs Computer (unbeatable AI)
- Score tracking
- Win-line highlighting

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080
